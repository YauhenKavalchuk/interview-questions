# 🎯 Front-end. Вопросы на собеседовании

Добро пожаловать в один из самых полных сборников вопросов для технических
собеседований на позицию **Junior / Middle / Senior Front-end разработчика**!
Здесь ты найдёшь сотни вопросов, сгруппированных по темам - от основ HTML и CSS
до архитектурных паттернов и безопасности. Каждый вопрос сопровождается
**подробным видеоответом**, чтобы подготовка занимала как можно меньше времени.
